# ⚙️ n8n Automation Workflows
  
  Direktori ini berisi arsitektur workflow n8n berformat `.json`. 
  
  **Cara Import:**
  1. Buka dashboard n8n.
  2. Klik `Workflows` > `Add Workflow`.
  3. Klik menu tiga titik (pojok kanan atas) > `Import from File`.
  4. Konfigurasikan *credentials* LLM (Groq/Gemini) Anda.
