# 🗄️ B2B Data Extraction Schema

This defines the standard JSON payload generated by the Python microservices and passed back to n8n.

## `LeadProfile` Object
- `id` (String, UUID): Unique identifier.
- `company_name` (String): Extracted organization name.
- `decision_maker_name` (String, Nullable): Extracted via LLM.
- `confidence_score` (Float): AI confidence in extraction (0.0 - 1.0).
- `metadata` (Object): Raw unparsed tags for audit purposes.
