# Security Policy

## Supported Versions
| Version | Supported          |
| ------- | ------------------ |
| v1.0.x  | :white_check_mark: |

## Reporting a Vulnerability
Untuk melaporkan masalah keamanan pada *pipeline* data atau kebocoran kredensial (API Key), harap jangan membuat *public issue*. 
Kirimkan email langsung ke arsitek utama (Ali Rosyid) untuk penanganan segera.
